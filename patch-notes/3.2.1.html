Patch Notes 3.2.1

Ironclad: Battle Tank for Android · 24 November 2026

Highlights

  • The gun now targets enemies on screen before enemies off screen.
  • Range upgrades are rebalanced so a full set fits the camera's view.
  • Each Rangefinder now pulls the camera back so its range stays on screen.
  • A What's New window now shows after each update.

Targeting

  • The gun now targets enemies on screen first. Previously it targeted the nearest enemy whether you could see it or not.
  • The gun only fires at an enemy off screen when nothing on screen can be hit.
  • The coax, drones, Javelin Pod, Artillery Uplink and other support weapons now target enemies on screen first.
  • Priority Targeting now picks the strongest enemy on screen before any enemy off screen.

Range

  • Range upgrades are rebalanced so a full set reaches the camera's furthest zoom. Previously they could reach far past the edge of the screen.
  • Long Barrel: +4% range a rank. Previously +15%.
  • Thermal Sights: +4% range (+7% at rank 2). Previously +15% (+25% at rank 2).
  • Tungsten Penetrator: +15% range. Previously +50%.
  • Long Gun: +6% range. Previously +25%.
  • Desert Optics: +2% range (+1% per rank). Previously +10% (+5% per rank).
  • Depot optics: +1% range per rank. Previously +2%.
  • Rangefinder: +1% range each. Previously +4%.
  • Each Rangefinder now pulls the camera back further so its range stays on screen.

Updates

  • A What's New window now shows the highlights of a new version with a link to its full patch notes.
  • Settings now shows the version number. Tapping it opens every version's patch notes.
